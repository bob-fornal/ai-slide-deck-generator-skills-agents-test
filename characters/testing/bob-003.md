## Note on `--size`

`--size=300x1200` was requested but is not honored by flux. Unlike the
earlier `bob-002.jpg` run, sending explicit `width`/`height` in the request
body this time caused a hard failure rather than being silently ignored:

```
AI generation failed: 5006: Error: Additional or unevaluated properties '/width, /height' at '/' not allowed
```

The request was retried with `width`/`height` omitted entirely, which
succeeded and returned the model's fixed 1024x1024 output. As with
`bob-002.jpg`, `--size` only actually takes effect with `--type=png`
(`@cf/stabilityai/stable-diffusion-xl-base-1.0`), which honors
`width`/`height` directly.
