## How the earlier NSFW block was resolved

`bob-006.md` documents this same model+prompt combination failing with
`3030: Input prompt contains NSFW content.` Before concluding the prompt
itself was the problem, we tested whether the filter is content-based or
just flaky:

- The exact same prompt that failed for `bob-006` was retried unchanged,
  5 times in a row: attempts 1–4 failed with the identical `3030` error,
  attempt 5 succeeded and produced this image.
- A completely unrelated, benign control prompt ("a red sports car in a
  parking lot") also got blocked on its first try, then succeeded 3/3 on
  immediate retries with no wording change.

**Conclusion: this is a flaky/probabilistic false-positive rate on
Leonardo's prompt filter, not a deterministic block on specific wording.**
No prompt change was needed for `lucid-origin` — plain retry got a clean
result with the original prompt text, and the output looks correct (full
body, all limbs and shoes visible, matches the requested description).
