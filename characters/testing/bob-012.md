## Note on `--size`

Sending `width`/`height` (304/608) failed immediately with the same hard
error seen every time flux is asked for a size:

```
AI generation failed: 5006: Error: Additional or unevaluated properties '/width, /height' at '/' not allowed
```

Retried with `width`/`height` omitted, which succeeded and returned the
model's fixed 1024x1024 output — no retry loop needed since this is a
deterministic, known limitation, not flakiness. Quality is good: a clean,
complete full-body character on an empty background.
